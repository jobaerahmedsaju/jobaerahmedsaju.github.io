# jobaerahmedsaju.github.io

Personal academic website of **Jobaer Ahmed Saju**, hosted with GitHub Pages.

## Files

- `index.html` — homepage
- `research.html` — research overview
- `projects.html` — selected projects and code portfolio
- `publications.html` — journal articles and selected presentations
- `cv.html` — CV summary
- `contact.html` — contact and academic profiles
- `assets/css/style.css` — site design
- `assets/js/main.js` — mobile navigation and small animations

## Publish

Upload these files to the root of the `jobaerahmedsaju.github.io` repository. GitHub Pages is already configured to deploy from `main` and `/ (root)`.

## Add a PDF CV later

Place the PDF here:

`files/Jobaer_Ahmed_Saju_CV.pdf`

Then add a download button in `cv.html` or the homepage.

## Replace the profile image

The homepage currently uses the public GitHub avatar automatically:

`https://github.com/jobaerahmedsaju.png`

To use a different photo, save it as `assets/images/profile.jpg` and replace the image URL in `index.html`.
